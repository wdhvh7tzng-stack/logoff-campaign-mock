# Log Off — Unscreened Advice

Responsive campaign landing page with original campaign images, local fonts, and an accessible artwork viewer.

## Run locally

Requires Node.js 20 or newer. No dependency installation is needed.

```sh
npm run dev
```

The development server uses port 3000; set `PORT` to override it.

```sh
npm run build
```

The standalone production files are written to `dist/`.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The root contains the static website and `.nojekyll` disables unnecessary Jekyll processing.

## Remaining content

Social media links and contact details still need verified official destinations. Their current footer placeholders do not link to profiles.
